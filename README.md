# Tiny Tracker

A cute, local daily tracker designed to help you keep tabs on your mood, habits, and daily notes. 

## Features
* **Mood Tracking:** Log how you're feeling each day.
* **Habit Tracker:** Keep up with your daily goals and routines.
* **Daily Notes:** Jot down thoughts, reminders, or journal entries.
* **Privacy-First:** Fully local operation (runs directly in your browser).

## Tech Stack
Built with simple web technologies:
* HTML (17.9%)
* CSS (33.6%)
* JavaScript (48.5%)
